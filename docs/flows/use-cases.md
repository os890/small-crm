# What each use-case does

The 26 use-cases of the application, as the end-to-end suite drives them, each with the
sequence diagram cdi-flow recorded while it ran. One block per request, in the order the
application handled them; the blocks are the recorded chains, unchanged.

Generated by `node e2e/scripts/record-flows.mjs` - the prose lives in
`e2e/scripts/use-case-descriptions.mjs`, everything else is recorded. The per-chain diagrams
each use-case is made of are in the directory linked from its heading.

## 4. a backup can be created, downloaded and restored from the folder

Creates a company, takes a backup, downloads it to confirm the company is really in it, adds a second company, and restores the backup: the later company is gone, the earlier one is back, and a before-restore copy of what was replaced has appeared in the folder.

Driven by `e2e/tests/backups.spec.ts`, passed. 29 request(s), 20 distinct chain(s) of 193 recorded — [all of them](backups/04-a-backup-can-be-created-downloaded-and-restored-from-the-folder/README.md).

Its 29 requests are too many to inline here: [`use-case.mmd`](backups/04-a-backup-can-be-created-downloaded-and-restored-from-the-folder/use-case.mmd).

## 5. an unwanted restore can be undone with the before-restore file

Restores an older backup on purpose and then restores the before-restore copy the application wrote by itself, which brings the newer state back.

Driven by `e2e/tests/backups.spec.ts`, passed, run with its whole spec in front of it. 78 request(s), 25 distinct chain(s) of 571 recorded — [all of them](backups/05-an-unwanted-restore-can-be-undone-with-the-before-restore-file/README.md).

Its 78 requests are too many to inline here: [`use-case.mmd`](backups/05-an-unwanted-restore-can-be-undone-with-the-before-restore-file/use-case.mmd).
